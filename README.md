# iluminint

Every 2 minutes, moves a lantern block above the player. If it collides with
something, it gives torches instead.

## Commands
- `/l_on`: enables the mod and the looping 2-minute countdown.
- `/l_off`: disables the mod and the countdown.
- `/fixme (2 to 8)`: removes the mod's lantern blocks in an area around the
  player. It only affects the lantern, never the terrain. Useful if you leave
  the game with the mod active and the last lantern stays on the map.

All of them appear in the `/help` list.

## Installation
Place the `iluminint` folder in `mods/` and enable the mod in your world.
